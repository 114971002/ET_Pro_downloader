惡意軟體/工具黑名單 (Software Denylist)

在此新增特定的工具或惡意軟體名稱。符合這些關鍵字的特徵將被標記在軟體黑名單內，以防止被系統的自學習引擎與威脅群組別名混淆。

IoC 開源情資來源設定 (CTI Feeds Toggle)

啟用或禁用特定的威脅情資來源。變更設定並點擊儲存後，系統將在下一次 CTI 同步時依此設定抓取。

Malpedia 威脅行為者擴充來源

啟用後，系統將在每次 Intel 更新時從 Malpedia 下載 900+ 個威脅行為者資料（包含 MITRE ATT&CK 尚未收錄的組織，如 Flax Typhoon、Volt Typhoon 等）， 補充至 actor_mappings.json 中，供規則比對與威脅歸因使用。

若擁有 Malpedia 帳戶，可至 Malpedia 設定頁 取得 API Token，可解鎖更多詳細資訊。
